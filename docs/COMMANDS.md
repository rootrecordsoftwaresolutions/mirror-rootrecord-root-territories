# Commands and permissions

## Commands

| Command | Description | Permission | Usage |
|---------|-------------|------------|-------|
| `/territories` | Territory border info and notification settings | `` | `/<command> [info/notifications]` |
| `/nationfounding` | Multi-town nation founding proposals and agreements | `` | `/<command> propose/agree/status/cancel` |
| `/rootterritories` | Reload territory zones and BlueMap markers | `rootterritories.reload` | `/<command> reload` |

## Permissions

| Permission | Description | Default |
|------------|-------------|---------|
| `rootterritories.reload` | Reload root-territories.yml and rebuild zones | `op` |
